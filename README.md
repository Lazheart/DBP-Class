# Implementacion de una api externa basada en roles


El dia de hoy vamos a implemtar un sistema de acceso basado en roles


#### Roles 

Los roles considerar son los siguientes

1. ADMIN
2. OPERATOR
3. CLIENT


### API Externa

La API debe seguir la convencion estar de metodo rest puedes encontrar mas api a eleccion libre en este [enlace](https://apilayer.com/)


## Limite y Uso

- El administrador puede realizar hasta 10 llamadas en un solo dia
- El operador 5 por dia 
- Mientras que el cliente puede realizar 5 por mes
